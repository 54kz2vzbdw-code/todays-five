# Today's Five

A five-line checklist built to be left open on screen all day.

- Click a line (or press its number) to cross it off — the strike draws across every
  line of wrapped text, the item settles to the bottom, and confetti fires from the cursor.
- **Edit list** to put your own items in. Up to eight lines.
- **T** cycles three themes; **M** mutes; **E** edits; **F** goes full screen.
- Progress is saved in your own browser. Nothing is sent anywhere, and each visitor
  gets their own private list.

Single self-contained HTML file. No build step, no dependencies except Google Fonts.
