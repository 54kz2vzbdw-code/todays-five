Today's Five

A short list you leave open on screen all day. This page says exactly what leaves your device, who can see it, and what is never collected.

How it works

When you start a list, your browser makes a random secret and puts it in the link, after the #. Everything else is derived from that secret on your device: the key that encrypts the list, the id the server files it under, and the token that proves you may change it. The part of a link after # is never sent to a server by a browser, and this app never sends it anywhere else.

Before anything is saved or synced, the whole list is encrypted on your device with AES-256-GCM. Other devices with the same link derive the same key and decrypt it. The edit link can produce a view link; a view link cannot produce the edit link.

What is stored on the server

  • The encrypted list: one sealed blob per list. Lines, notes, sections, history and saved themes are all inside it.
  • A revision number and two timestamps (last change, last opened to the day), so devices can tell what changed and idle lists can be cleared out.
  • A hash of the write token, so the server can refuse changes from a view link.
  • A salted hash of your network address, kept for at most 24 hours, only when a new list is created. It exists to stop one address from creating lists without limit. The address itself is not stored.

What the operator can see

Nothing readable. The person running this site can see that a list exists, how large its encrypted blob is, when it last changed and when it was last opened. Not a word of what is in it, not who opened it, and not the link. There is no way to recover a list for you: lose the link, lose the list.

Third parties

The encrypted lists are stored with Supabase (a hosted Postgres database and realtime service) in a data centre in the United States run by Amazon Web Services. Supabase sees the same things the operator sees, plus the ordinary connection metadata any server sees (your network address, request times). The app itself is served by GitHub Pages. Fonts and every other file load from this site; nothing is fetched from Google, a CDN or anyone else.

Retention

A list that nobody has opened or changed for 12 months is deleted from the server. Your device keeps its own copy for as long as the browser keeps site data. Rotating a link deletes the old encrypted blob at once.

What there is none of

  • No accounts, no sign-up, no email, no passwords.
  • No analytics, no trackers, no cookies. The browser's own storage holds your theme and your links, on your device only.
  • No names or presence: the list does not record who changed what.

Sharing

Anyone with the edit link can change anything, including making new links. Anyone with the view link can read everything until you rotate. Treat the edit link like a password.

Limits

This is a small free service. Each list is capped at 96 KB encrypted (a year of daily history fits many times over), the service holds a few thousand lists in total, and a single network address may create only a handful of lists per hour. When a limit is hit, the app says so and keeps working on your device.

The code is on GitHub for anyone who wants to check these claims against what actually runs.
