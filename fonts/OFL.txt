Today's Five - font licences
============================

Today's Five sets text in 22 typeface families. Every one of them comes from
Google Fonts and every one is licensed under the SIL Open Font License,
Version 1.1. This file is the notice the licence asks to travel with them: the
copyright statement for each family, its Reserved Font Name where it declares
one, and the full text of the licence, once, at the end.

None of the files shipped here is an original release. Each is the latin
subset that Google Fonts serves, which is already a subset of the designer's
release with most of its name records stripped - the licence description (name
ID 13) and the trademark record (name ID 7) are gone from all 33 faces before
this project ever downloaded them, which is why this file exists. The copies
in the Apple app bundle are converted from woff2 to TrueType, and where the
source is a variable font they are instanced to a single static weight and
renamed with that weight. Under OFL 1.1 all of that makes them Modified
Versions - "by changing formats", in the licence's own words. They are
redistributed under this same licence and no other, and none of them is sold
on its own.

The web build carries these families as fonts/*.woff2 (27 files); the Apple
app bundles the same faces as TTF (33 files).

Each copyright statement below is quoted from that family's OFL.txt in
google/fonts (github.com/google/fonts, ofl/<slug>/OFL.txt), which is the
upstream of record. Where the copyright baked into the shipped binaries' own
name table (name ID 0) says something different, both are given and labelled.

A note on the reserved names
----------------------------

Nine of the 22 families declare a Reserved Font Name that the shipped faces
still carry in their primary font name: IBM Plex Mono, IBM Plex Sans, Josefin
Sans, Lato, Lora, Playfair Display, PT Sans, Quicksand and Source Serif 4 - 15
of the 33 faces in the app bundle. OFL 1.1 asks a Modified Version not to do
that. These files inherit the names from the subsets Google Fonts itself
serves under those same names, and the format conversion done here did not
change them. The point is recorded rather than argued: if a copyright holder
asks, the names change and this file changes with them.

DM Serif Display declares the reserved name "Source" and does not use it in
its font name. Source Serif 4 is the reverse: its current upstream OFL.txt
declares no reserved name at all, while the 4.004 binaries shipped here still
assert "with Reserved Font Name 'Source'" in their copyright notice. It is
counted above on the strength of what the shipped bytes say.
